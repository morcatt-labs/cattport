# Changelog

## 1.0.0 beta 6

- **Online or not:** a green or red dot on each app shows whether its service responds, checked when Cattport opens
- **Order:** drag tiles to change their order, or use Alt and the arrow keys; Save to DSM sends the order to the DSM menu
- **Several at once:** choose Select, pick apps, then change who sees them, hide them or show them
- **New addresses:** when a container's port or the NAS address changes, Cattport offers to update the tiles
- A longer description in Package Center

## 1.0.0 beta 5

- Package Center shows how many times Cattport was downloaded, updated every day
- "What's new" in Package Center lists each change on its own line

## 1.0.0 beta 4

- **Chosen people:** show an app only to the users and groups you pick, or to everyone except some of them. Cattport sets the matching DSM Application Privileges when you save.
- **Updates in Package Center:** add the Morcatt Labs package source to get new versions straight in DSM
- Tiles now open through Cattport, which checks who is signed in, so someone who isn't allowed can't open a tile by its link
- Tile addresses are no longer in files anyone can download from DSM without signing in
- App names and descriptions can't contain markup, which DSM would show in its menu
- Safer checks for addresses, backups and imports
- The arrow in the Language list now sits inside its box

## 1.0.0 beta 3

- Icon suggestions appear much faster: online and Docker searches now run at the same time
- Fixed a message asking to reload DSM that could stay after an update, which also stopped Save to DSM from restarting Cattport
- The icon search message moved to the icon panel; the pencil pulses while searching

## 1.0.0 beta 2

- Clearer wording while saving: "Updating…" and "DSM updated" replace "Publishing"

## 1.0.0 beta 1

First beta.

- Add Docker services and links as tiles in the DSM menu
- Save to DSM applies changes for every browser and user
- Local and domain address for each tile
- Only admins, Everyone and Hide
- Icon picker with suggestions, File Station thumbnails and search
- 21 DSM languages plus Romanian
- Backup, diagnostics and help
